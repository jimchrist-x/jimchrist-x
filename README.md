### Hi, I'm Jim 👋

Software developer based in Greece. I build small, working tools — CLI utilities, desktop apps and browser extensions — and I'd rather finish something usable than keep a folder of half-started projects.

Most of my code is **Java** and **C**, with **Python** for scripting and **JavaScript** when the browser is the platform.
